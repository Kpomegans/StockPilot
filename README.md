# StockPilot

Application moderne de gestion de stock, caisse enregistreuse et facturation sécurisée (FCFA, Mobile Money Flooz & T-Money).

## Structure du Projet (Vite + React)

```
StockPilot/
├── dist/                  # Fichiers de production compilés
├── node_modules/          # Dépendances npm
├── public/                # Ressources publiques statiques
├── src/
│   ├── assets/            # Icônes, images et SVG
│   ├── App.css            # Styles du composant principal
│   ├── App.jsx            # Application StockPilot React complète
│   ├── index.css          # Styles globaux et variables CSS
│   └── main.jsx           # Point d'entrée React 18
├── .gitignore
├── eslint.config.js       # Configuration ESLint 9
├── index.html             # Point d'entrée HTML Vite
├── package.json           # Scripts et dépendances
├── README.md
└── vite.config.js         # Configuration Vite React
```

## Démarrage rapide

```bash
# Installation des dépendances
npm install

# Lancement en mode développement
npm run dev

# Compilation pour la production
npm run build

# Aperçu de la version de production
npm run preview
```
